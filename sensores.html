04 / DATOS / EN DESARROLLO

Reconstrucción de sensores

¿Cómo recuperar una señal con lecturas faltantes?

El planteamiento

El modelo propuesto utiliza datos sintéticos de una función conocida para comparar reconstrucciones y medir el error.

Métodos previstos: Interpolación de Lagrange, Newton y splines cúbicos.

Escenarios propuestos

Normal: nodos regulares y datos consistentes.

Estrés: mayor ruido o más lecturas faltantes.

Mal condicionado: nodos desfavorables con sensibilidad por verificar.

Este módulo aún no tiene simulador ni resultados implementados.
